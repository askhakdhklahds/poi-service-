# 09 15 分钟生活圈评估

## 目标

能讲清“人口网格 → 设施覆盖 → 覆盖率/盲区 → 页面”的完整链路，以及数据的口径和局限。

## 解决什么问题

原来的平台只能回答“附近有什么”，生活圈要回答：

> 这个区的居民，15 分钟内能不能到达医疗/教育/商业/文体/交通设施？覆盖多少人口？哪里是盲区？

## 数据

```
WorldPop 2020 中国 1km GeoTIFF
  → worldpop_to_grid.py（裁剪上海 bbox）
  → pop_grid_1km.csv（15,237 个网格）
  → load_population_grid.sql
  → population_grid（9,422 个网格落在区内）
```

- WorldPop 是“每像元人数”，按块求和，不取平均。
- 1km 旧版是未约束估计，上海区县合计约 3,220 万；按 2020 年七普 24,870,895 统一校准。
- 统一缩放不改变覆盖率，只校准人口绝对值。

## 表

- `population_grid`：grid_x/grid_y、lon/lat、pop、district_adcode、geom 4326/4549。
- `facility_standard`：code、name_zh、poi_category、threshold_seconds、euclid_radius_m。

## 覆盖 SQL

`service/life_circle/CoverageService.java`：

```sql
WITH covered AS (
  SELECT g.id, min(ST_Distance(p.geom_4549, g.geom_4549)) AS distance_m
  FROM population_grid g
  JOIN poi p ON ST_DWithin(p.geom_4549, g.geom_4549, ?)
  WHERE g.district_adcode = ? AND p.category = ?
  GROUP BY g.id
),
cells AS (
  SELECT g.id, g.pop, g.geom, g.cell_size_m, c.distance_m,
         (c.id IS NOT NULL) AS covered
  FROM population_grid g
  LEFT JOIN covered c ON c.id = g.id
  WHERE g.district_adcode = ? AND g.pop > 0
)
SELECT count(*), count(*) FILTER (WHERE covered),
       sum(pop), sum(pop) FILTER (WHERE covered), ...
FROM cells;
```

- 半径 = 步行秒数 × 1.2 m/s：5/10/15 分钟 → 360/720/1080 米。
- 输出 `popTotal / popCovered / coverageRatio / gapPopulation`。
- 返回 FeatureCollection：绿色覆盖格、红色盲区格。

## 页面

`src/main/resources/static/life-circle.html`：

- 影像底图：`World_Imagery`，地图 `maxZoom=18`。
- 行政区、设施类型、5/10/15 分钟。
- 绿色覆盖格 / 红色盲区格。
- 摘要卡片：覆盖人口、覆盖率、盲区人口、网格数。
- 点网格看人口、是否覆盖、最近设施距离。
- 支持 URL 参数自动评估。
- CDP 验证：34 个可见网格，摘要 97.2% / 658,413 人；截图 `shot_life_circle_cdp.png`。

## 局限与下一步

- 当前是欧氏半径，不是路网等时圈；下一步接 `pgr_drivingDistance`。
- 1km 网格较粗；更高精度换 WorldPop 100m constrained 数据。
- 人口是模型估计，不是真实居民出行调查。
- 设施分类只用了现有 POI 的 5 类，养老等设施需要补充数据。

## 面试问答

**Q：为什么用人口网格而不是行政区人口？**

A：行政区人口只能算区级覆盖率；网格能定位到具体盲区，也能按人口加权。

**Q：为什么校准？**

A：WorldPop 1km 旧版偏高；按七普总人口统一校准，绝对值更可信，覆盖率不变。

**Q：为什么不用路网？**

A：MVP 先用欧氏半径快速验证；路网等时圈是下一步，需要步行道路过滤和 `pgr_drivingDistance`。
