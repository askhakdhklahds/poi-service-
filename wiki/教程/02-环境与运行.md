# 02 环境与运行

## 目标

能把数据库、缓存、后端、GeoServer 跑起来，并能排查常见启动问题。

## 组件与端口

| 组件 | 地址 | 账号 |
|---|---|---|
| Spring Boot | http://localhost:8081 | admin/admin123 等 |
| PostgreSQL | 127.0.0.1:5432 / 库 `poi` | postgres/postgres |
| Memurai（Redis） | 127.0.0.1:6379 | 无密码 |
| GeoServer | http://localhost:8080/geoserver | admin/geoserver |

## 启动

```cmd
:: PostgreSQL
D:\gis-env\pgsql\bin\pg_ctl.exe -D D:\gis-env\pgsql\data start

:: Memurai 已作为 Windows 服务运行
sc query Memurai

:: Spring Boot
mvn -f D:\jue\gis\poi-service\pom.xml spring-boot:run
```

## 配置

`src/main/resources/application.yml`：

- `server.port: 8081`
- HikariCP：max 10 / min-idle 2
- Flyway：`classpath:db/migration`
- Redis：`127.0.0.1:6379`，缓存 TTL 5 分钟
- Agent：DeepSeek OpenAI 兼容接口，Key 从环境变量注入
- 瓦片目录：`tiles/`、`tiles-gcj/`

## 常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| 8081 被占用 | 旧进程没退 | `netstat -ano \| findstr :8081`，kill PID |
| 地图没底图 | Esri/AMap 网络问题 | 换网络或看控制台 |
| 看不到 POI | MVT 渲染/缓存 | 打开 `points.html` 保底 |
| 行政区统计不准 | 物化视图没刷新 | `POST /api/admin/refresh-stats` |
| 生活圈没数据 | `population_grid` 为空 | 跑 `worldpop_to_grid.py` + `load_population_grid.sql` |
| Redis 连不上 | Memurai 没启动 | 启动 Memurai 服务 |

## 面试点

- 为什么 Spring Boot 用 8081？因为 GeoServer 占用 8080。
- 为什么 Rock 用 Memurai？Windows 上兼容 Redis 协议。
- 为什么 Flyway？建表版本化、可重复执行、新环境一键迁移。
