# 15 分钟生活圈详解

> 这篇只讲生活圈：人口数据怎么来、怎么入库、覆盖率怎么算、接口怎么返回、前端怎么可视化、怎么测。
> 主流程文档见 [项目全流程详解](项目全流程详解.md)。

---

## 1. 业务问题

原来的平台只能回答“附近有什么”。生活圈要回答：

> 这个区的居民，15 分钟内能不能到达医疗/教育/商业/文体/交通设施？覆盖多少人口？哪里是盲区？

核心指标：

- 覆盖人口 `popCovered`
- 总人口 `popTotal`
- 覆盖率 `coverageRatio = popCovered / popTotal`
- 盲区人口 `gapPopulation = popTotal - popCovered`
- 网格数 `cellCount`

## 2. 人口数据从哪来

### 2.1 数据源

- WorldPop 2020 中国 1km GeoTIFF；
- 许可：CC-BY-4.0；
- 每个像元的值是“该像元内的人数”。

### 2.2 生成脚本

`scripts/worldpop_to_grid.py`：

1. 从 `scripts/data/shanghai_districts.json` 算上海 bbox；
2. 用 `rasterio.windows.from_bounds` 裁剪窗口；
3. 读取窗口数据，nodata → 0，负数 → 0；
4. 按 `factor=1`（1km）逐像元求和；
5. 每个像元输出 `grid_x, grid_y, lon, lat, pop`；
6. 写 `scripts/data/pop_grid_1km.csv`。

关键代码：

```python
left, bottom, right, top = bbox_from_geojson(args.boundary)
left -= args.pad; bottom -= args.pad; right += args.pad; top += args.pad

with rasterio.open(args.src) as src:
    window = from_bounds(left, bottom, right, top, transform=src.transform)
    window = window.round_offsets().round_lengths()
    data = src.read(1, window=window)
    transform = src.window_transform(window)
    if src.nodata is not None:
        data = np.where(data == src.nodata, 0, data)
    data = np.where(np.isfinite(data), data, 0)
    data = np.maximum(data, 0).astype("float64")

    for row in range(0, rows, factor):
        for col in range(0, cols, factor):
            pop = float(data[row:row_end, col:col_end].sum())
            if pop <= 0: continue
            lon, lat = xy(transform, center_row, center_col)
            grid_x = (int(window.col_off) + col) // factor
            grid_y = (int(window.row_off) + row) // factor
            out_rows.append((grid_x, grid_y, round(lon, 6), round(lat, 6), round(pop, 3)))
```

运行：

```bash
python scripts/worldpop_to_grid.py \
  --src scripts/data/chn_pop_2020_1km.tif \
  --out scripts/data/pop_grid_1km.csv --factor 1
```

实测输出：

```
cells=15237 total_pop=37998190
```

`total_pop=37,998,190` 是上海 bbox（含周边）的原始估计，不是上海行政区总人口。

### 2.3 为什么校准

WorldPop 1km 旧版是未约束估计，上海区县合计约 3,220 万，高于七普 2,487 万。

`load_population_grid.sql` 做统一校准：

```sql
WITH total AS (
    SELECT sum(pop) AS raw_pop
    FROM population_grid
    WHERE district_adcode IS NOT NULL
)
UPDATE population_grid g
SET pop = g.pop * (24870895.0 / t.raw_pop)
FROM total t
WHERE g.district_adcode IS NOT NULL
  AND t.raw_pop > 0;
```

- 统一缩放不改变覆盖率；
- 只校准人口绝对值口径；
- 校准后区内总人口 = 24,870,895。

## 3. 表结构

### 3.1 `population_grid`

```sql
CREATE TABLE population_grid (
    id              bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    grid_x          integer NOT NULL,
    grid_y          integer NOT NULL,
    cell_size_m     integer NOT NULL DEFAULT 500,
    lon             double precision NOT NULL,
    lat             double precision NOT NULL,
    pop             double precision NOT NULL CHECK (pop >= 0),
    district_adcode varchar(12),
    geom            geometry(Point, 4326) NOT NULL,
    geom_4549       geometry(Point, 4549) NOT NULL,
    UNIQUE (grid_x, grid_y, cell_size_m)
);
CREATE INDEX idx_population_grid_geom_4549
    ON population_grid USING GIST (geom_4549);
CREATE INDEX idx_population_grid_district_pop
    ON population_grid (district_adcode, pop);
```

### 3.2 `facility_standard`

```sql
CREATE TABLE facility_standard (
    code              text PRIMARY KEY,
    name_zh           text NOT NULL,
    poi_category      text NOT NULL,
    threshold_seconds integer NOT NULL DEFAULT 900,
    euclid_radius_m   integer NOT NULL DEFAULT 1080,
    enabled           boolean NOT NULL DEFAULT true
);
```

种子数据：

| code | 名称 | poi_category | 说明 |
|---|---|---|---|
| healthcare | 医疗 | 医院 | 医院 POI |
| education | 教育 | 学校 | 学校 POI |

### 4.3 生成几何 + 归属行政区

```sql
TRUNCATE population_grid RESTART IDENTITY;

INSERT INTO population_grid
    (grid_x, grid_y, cell_size_m, lon, lat, pop, district_adcode, geom, geom_4549)
```

## 5. 覆盖算法

### 5.1 半径

步行速度按 1.2 m/s：

```
5 分钟  → 300 秒 → 360 米
10 分钟 → 600 秒 → 720 米
15 分钟 → 900 秒 → 1080 米
```

`CoverageService`：

```java
int radius = Math.max(1, Math.round(thresholdSeconds * 1.2f));
```

### 5.2 覆盖 SQL

```sql
WITH covered AS (
    SELECT g.id,
           min(ST_Distance(p.geom_4549, g.geom_4549)) AS distance_m
    FROM population_grid g
    JOIN poi p ON ST_DWithin(p.geom_4549, g.geom_4549, ?)
    WHERE g.district_adcode = ?
      AND p.category = ?
    GROUP BY g.id
),
cells AS (
    SELECT g.id,
           g.pop,
           g.geom,
           g.cell_size_m,
           c.distance_m,
           (c.id IS NOT NULL) AS covered
    FROM population_grid g
    LEFT JOIN covered c ON c.id = g.id
    WHERE g.district_adcode = ?
      AND g.pop > 0
)
SELECT count(*) AS cell_count,
       count(*) FILTER (WHERE covered) AS covered_cells,
       coalesce(sum(pop), 0) AS pop_total,
       coalesce(sum(pop) FILTER (WHERE covered), 0) AS pop_covered,
       max(cell_size_m) AS cell_size_m,
       (SELECT jsonb_build_object(
           'type', 'FeatureCollection',
           'features', coalesce(jsonb_agg(jsonb_build_object(
               'type', 'Feature',
               'geometry', ST_AsGeoJSON(
                   ST_Expand(cells.geom,
                             cells.cell_size_m / 2.0 / 111320.0))::jsonb,
               'properties', jsonb_build_object(
                   'gridId', cells.id,
                   'pop', round(cells.pop),
                   'covered', cells.covered,
                   'nearestM', round(cells.distance_m)
               )
           )), '[]'::jsonb)
       )::text FROM cells) AS geojson
FROM cells;
```

### 5.3 这段在做什么

1. `covered`：对每个网格，找半径内最近的设施，得到 `distance_m`。
2. `cells`：把 `covered` 左连接到所有人口 > 0 的网格；`covered = true/false`。
3. 外层聚合：
   - 网格数；
   - 覆盖网格数；
   - 总人口；
   - 覆盖人口；
   - 网格大小；
   - FeatureCollection。
4. `ST_Expand`：把 1km 点扩成 1km 方格，前端画网格。
5. `jsonb_build_object`：在数据库里直接拼 FeatureCollection，避免 Java 循环。

### 5.4 Redis 缓存


## 7. 前端页面详解

`src/main/resources/static/life-circle.html`：

### 7.1 初始化

1. `MapLibre` 加载影像底图 `World_Imagery`，`maxZoom=18`；
2. `Promise.all` 请求：
   - `/api/district/list` → 行政区下拉；
   - `/api/life-circle/categories` → 设施分类下拉；
3. 支持 URL 参数：
   `?adcode=310101&category=healthcare&threshold=900`。

### 7.2 点击评估

```js
async function runCoverage() {
  const url = `/api/life-circle/coverage?adcode=${adcode}` +
    `&category=${category}&threshold=${threshold}`;
  const response = await fetch(url);
  const json = await response.json();
  const data = json.data;
  renderSummary(data);
  ensureGridLayers(data.geojson);
  fitToGeoJson(data.geojson);
}
```

### 7.3 摘要卡片

```js
popCovered.textContent = formatNumber(data.popCovered);
coverageRatio.textContent = (data.coverageRatio * 100).toFixed(1) + '%';
gapPop.textContent = formatNumber(data.gapPopulation);

```

### 7.4 网格图层

```js
map.addSource('life-grid', { type: 'geojson', data: geojson });

  id: 'life-grid-line',

```

- 绿色 = 已覆盖；
- 红色 = 盲区；
- 点击网格显示人口、是否覆盖、最近设施距离。

```js

  maxZoom: 14,
```

## 10. 局限与下一步

### 当前局限

1. **欧氏半径**，不是路网等时圈；
2. **1km 网格**偏粗；
3. 人口是模型估计，按七普统一校准，不是真实出行调查；
4. 设施分类只用了 5 类，养老等设施需要补数据；
5. 没有考虑地形、河流、过街天桥等障碍；
6. 覆盖率是“半径内有设施”，不是“真实步行路径可达”。

### 下一步

1. `pgr_drivingDistance` 做路网等时圈；
2. 500m 或 250m 网格；
3. WorldPop 100m constrained 数据；
4. 2SFCA 供需匹配；
5. 补点推荐（最大覆盖选址）；
6. 情景模拟：新增设施后覆盖率提升多少。

## 11. 面试问答

**Q：为什么用人口网格？**

行政区人口只能算区级覆盖率；网格能定位盲区，并按人口加权。

**Q：为什么校准？**

1km 旧版偏高；按七普总人口统一校准，绝对值更可信；覆盖率不受统一缩放影响。

**Q：覆盖率怎么算？**

`ST_DWithin(poi.geom_4549, grid.geom_4549, radius)`；`radius = threshold × 1.2`；汇总覆盖人口/总人口。

**Q：盲区怎么找？**

`covered=false` 且人口 > 0 的网格；前端红色显示；人口多但未覆盖优先。

**Q：为什么黄浦 97.2%、浦东 31.9%？**

黄浦面积小、医院密集；浦东面积大、分布不均。这是模型结果，不是官方统计。

**Q：生活圈是路网还是直线？**

当前欧氏半径，MVP；下一步用 `pgr_drivingDistance` 做路网等时圈。

**Q：前端怎么可视化？**

`life-circle.html`：影像底图 + 绿色覆盖格 + 红色盲区格 + 摘要卡片；CDP 验证 34 个可见网格，截图 `shot_life_circle_cdp.png`。
