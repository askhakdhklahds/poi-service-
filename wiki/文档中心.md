# 文档中心

本目录是城市 POI 空间分析平台的说明文档，按“先跑起来 → 懂数据 → 懂查询 → 懂 Agent → 能面试”的顺序组织。

## 项目一句话

> 基于 Spring Boot 3 + PostgreSQL/PostGIS 的城市 POI 空间分析平台：导入 85,864 条真实上海 OSM POI 与 16 个真实行政区，支持周边/最近邻/缓冲区/行政区统计、MVT 矢量瓦片、GeoServer WMS/WFS、Valhalla 高精度路线（本地 pgRouting 兜底），以及 EchoMind 风格的分层空间 Agent；并新增了基于 WorldPop 人口的 15 分钟生活圈覆盖评估。

## 快速启动

```cmd
:: 1. 启动 PostgreSQL / Memurai
D:\gis-env\pgsql\bin\pg_ctl.exe -D D:\gis-env\pgsql\data start
:: Memurai 作为 Windows 服务运行

:: 2. 启动 Spring Boot
mvn -f D:\jue\gis\poi-service\pom.xml spring-boot:run
```

## 数据与许可

| 数据 | 来源 | 数量 | 许可 |
|---|---|---|---|
| POI | OpenStreetMap 上海提取 | 85,864 | ODbL 1.0 |
| 行政区 | 阿里云 DataV | 16 个区 | 注明来源 |
| 人口 | WorldPop 2020 中国 1km | 15,237 个网格（9,422 个落在区内） | CC-BY-4.0 |
| 路网 | OpenStreetMap 上海路网 | `road_main` 84,203 条边 | ODbL 1.0 |
| 压测 | 程序生成 | 10,010,000 条合成点 | 仅压测，不代表真实业务 |

> WorldPop 1km 旧版是未约束估计，上海区县合计约 3,220 万；导入脚本按 2020 年七普 24,870,895 做统一校准。统一缩放不改变覆盖率，只校准人口绝对值。
